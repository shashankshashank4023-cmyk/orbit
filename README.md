# Orbit

**Modern living, made simple.**

Orbit is a responsive, editorial-style storefront concept for thoughtfully curated home furnishings. It pairs seasonal storytelling with a simple product browsing and shopping-bag experience.

## Live demo

[Explore Orbit](https://shashankshashank4023-cmyk.github.io/orbit/)

## Store experience

- Seasonal homepage with featured collections and design-led storytelling
- Curated categories: seating, lighting, objects, and textiles
- Featured products: Solace Lounge Chair, Arc Table Lamp, Onda Vase No. 03, and Haven Throw
- Shopping bag with add/remove controls, item count, and running subtotal
- Responsive navigation, delivery messaging, and newsletter section

## Built with

- HTML, CSS, and vanilla JavaScript
- Google Fonts and remotely hosted Unsplash photography

Orbit is a lightweight static site with no framework or build step.

## Run locally

1. Clone or download the repository.
2. Open index.html in a browser, or run `python -m http.server 8000` from the project folder.
3. Visit http://localhost:8000.

## Prototype scope

Product data is static and the shopping bag is kept only in the current page session. Search, filters, checkout, and newsletter submission show interface feedback but are not connected to a backend, payment provider, or email service. The project does not include customer accounts, live inventory, or order processing.

## Project files

- index.html — storefront structure
- styles.css — responsive visual styling
- app.js — product display and shopping-bag interactions
