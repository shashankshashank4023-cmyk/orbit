# Orbit

**Modern living, made simple.**

Orbit is an editorial-style e-commerce storefront for thoughtfully curated home furnishings. It brings product discovery and a calm, design-led shopping experience together in one place.

## Features

- Seasonal homepage with featured collections
- Product browsing across seating, lighting, objects, and textiles
- Product search, filters, and add-to-bag controls
- Design journal and newsletter sections
- Store messaging for delivery and returns
